# Starship Take-Off Human Playtest

This is the fastest feedback form for the current build of `Starship Take-Off`.

## What To Test

If you are short on time, this is the minimum useful path:

1. Start the game from the anthology menu.
2. Play one run in `Reimagined` mode.
3. Optionally try `Retro BASIC` mode for comparison.
4. Fill in the checkbox answers below and add any sharp observations at the end.
